AetherMaster 技術仕様 & DSP分析 (v6.0.0)

Web Audio API 信号フロー、プレ・クリッパー、アカデミックEQ設計、非線形倍音伝達関数の音響物理仕様

AetherMaster は、最新のブラウザ標準である Web Audio API を用いて、クライアントサイド（ブラウザ内）だけで極めて低遅延・高音質なマスタリングを実行する仮想ハードウェア/DSPスイートです。

サーバーに音声を一切送信せず、ローカルのCPUとブラウザの専用オーディオスレッドを使用してリアルタイムにDSP処理を実行します。以下に、本ツールが採用している最新の音声信号パス（Signal Chain）と音響工学的スペックの詳細を解説します。

DSP シグナルパス (信号フロー全12ステージ)

音声信号は、デコードされた AudioBuffer から再生（またはオフラインレンダリング）される際、以下の順序で直列・並列に接続された各DSPノードを通過します。

ステージ 使用ノード 処理概要と音響工学的目的
1. Input Gain & True Peak走査 GainNode L/R独立ピーク走査によりステレオ音源の真の最大振幅を検知。マスタリング回路への過入力を防ぎ、正確なヘッドルーム（-6.0 dBFS）を前段で確保します。
2. Noise Cleaner (Rumble & Hiss) BiquadFilterNode × 3, WaveShaperNode, GainNode × 2 Rumble Cut (HPF): 80Hz以下の空調振動や電源ハムを物理遮断。
Hiss Reducer (2-Band Double-Shelf): 9kHz以上のヒスを減衰させるハイシェルフと、16kHz以上のAir帯域を逆相復元するハイシェルフを直列接続。サイドチェーンエンベロープで動的にフラット（0dB）に戻し、無音時のサー音だけをカット。
3. Parallel Audiophile Saturator WaveShaperNode (並列), BiquadFilterNode × 2, GainNode (Dry/Wet) 真空管（TUBE）、磁気テープ（TAPE）、BJTソリッドステート（DRIVE）の3系統モデリング。
サブベース保護回路 (220Hz HPF): 歪み経路の手前で220Hz以下をカットし、キックやベースの巨大振幅による混変調歪み（IMD/モワつき）を100%防止。原音の芯とタイトさを保ったまま、中高域に上質な倍音だけを並列合算します。
4. 5-Band Academic EQ BiquadFilterNode × 7 ISO 226 等ラウドネス曲線（人間の耳の感度特性）に基づき、聴覚疲労を起こしやすいプレゼンス帯の過剰ブーストを廃止したプロ仕様設計。
  • eqLow: 80Hz Low Shelf
  • eqLowMid: 200Hz Peaking（温かみ・こもり制御）
  • kickPeaking: 55Hz Narrow Peaking (Q=2.0, キック胴鳴り専用)
  • eqMid: 1000Hz Peaking（ボーカルのボディ感）
  • eqMidHigh: 4500Hz Peaking（声の子音・明瞭度）
  • eqHigh: 9000Hz High Shelf
  • airShelf: 15000Hz Ultra-High Shelf（空気感専用）
5. AI Sibilance Notch (De-esser) BiquadFilterNode (Peaking, dynamic cut) ボーカルのサ行（シビランス）を動的に除去。設定された周波数範囲から幾何平均中心周波数とQ値をリアルタイム自動算出し、ボーカルの艶を削ることなく痛いトゲだけを急峻に抑制します。
6. Glue Compressor DynamicsCompressorNode アナログスタイルのソフトニー（18dB）により、楽曲全体を1枚のマスターテープに接着（Glue）したような一体感を形成。キックの打頭を逃がすため、KICK PUNCH時はアタックが自動で+30ms遅延されます。
7. M/S Stereo Imager ChannelSplitterNode, GainNode × 4, BiquadFilterNode (Side HPF) 音源を Mid（センター）と Side（広がり）にマトリックス変換。ボーカル・キックのセンター定位（Mid=1.0）を維持しつつ、Sideの可変ハイパス（110Hz〜140Hz）で低音の位相打ち消しを完全に防止します。
8. Maximizer Pre-Gain Boost GainNode マキシマイザーの押し上げ量をデシベル単位で増幅する純粋なリニアゲインステージです。
9. Pre-Limiter Soft Clipper WaveShaperNode (65,536 samples) 本ツールの核心技術。リミッターに入る直前で、ミリ秒未満の鋭い過渡ピーク（ドラムのアタックなど）を多項式ハイブリッド・ソフトニー曲線で自然に丸め込みます。リミッターの息継ぎ歪み（ポンピング）を根絶し、音圧とダイナミクスを両立します。
10. Brickwall Limiter DynamicsCompressorNode 高速アタック（1.0ms）と適応型リリース（80ms）で動作するブリックウォールリミッター。3dBのクッション（Look-aheadエミュレーション）により、超過エネルギーを滑らかに制御します。
11. Safety Soft-Clipper WaveShaperNode 最終段で発生しうるデジタルクリッピング（ビビリ音）を完全に防止する安全装置。振幅 0.96 (-0.35dB) までは完全透明、それを超える突発ピークのみを滑らかにサチュレーションさせます。
12. Ceiling Gain GainNode ストリーミング配信サイト（Spotify, Apple Music, YouTube等）で不可逆圧縮（AAC/MP3）された際のクリッピング（True Peak歪み）を防ぐため、最終天井を -1.0dBFS にマージン制御して完結します。

アナログモデリングの数学的伝達関数

サチュレーターおよびプレ・クリッパーで使用されている WaveShaper 用の伝達関数（カスタムカーブ計算）は、音響工学の物理特性に基づき以下の代数式を用いてリアルタイムに生成されています。

// 1. Pre-Limiter Soft Clipper (65,536 samples / 連続微分可能C-infinityソフトニー・ドライブ) f(x) = x [Drive = 0dB (完全ビット透明バイパス)] f(x) = sgn(x) * ((1 - α) * |x| + α * (tanh(k * |x|) / tanh(k))) [Drive > 0dB (k = 10^(Drive/20), α = Drive/6.0)] // 2. TUBE (三極真空管モデリング: 第2次偶数倍音主体 & DCオフセット完全相殺) f(x) = tanh(k * (x + 0.06)) - tanh(0.06 * k) [k = 1.0 + (Drive / 100) * 4.0] // 3. TAPE (オープンリール磁気テープ: 第3次奇数倍音対称ヒステリシス) f(x) = tanh(k * x) / tanh(k) [k = 0.5 + (Drive / 100) * 5.5] // 4. DRIVE (BJTディスクリート・コンソール: 直角クランプ全廃・マスタリング級ドライブ) f(x) = tanh(k * x) / tanh(k) [k = 0.8 + (Drive / 100) * 4.5]
